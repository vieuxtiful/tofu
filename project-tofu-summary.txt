project ToFU 
とうふ ARCHITECTURE

xx Fully automated: Flip all toggles to "auto" and let the pipeline run end-to-end

xx Fully manual: Flip all toggles to "manual" and control every step

xx Hybrid: Auto-run cicerone() and scene(), manually refine masks, auto-run cleanse() and scribe(), manually verify with verify()

Each function returns structured data that the user can inspect and modify at any point. The tofu() toast notifications become the user's guide through the process.

LYR/FXN 1: CICERONE (the most needed)
""""
(Italian for "guide" — it shows the localizer where everything is)

Detect all text regions in the source image/video frame
2. Generate precise bounding boxes and segmentation masks
3. Identify text characteristics (font style, color, size, positioning)
4. Output a TextManifest — a structured map of every text instance in the asset

Analyze what's behind each text region (brick wall, person's shirt, digital UI, etc.)
2. Identify visual elements that need preservation (gradients, patterns, textures)

4. Output a StyleProfile and BackgroundProfile for each text instance
